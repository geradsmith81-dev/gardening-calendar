# Biodynamic Gardening Calendar - home-screen launcher

A small page that gives the [Biodynamic Gardening Calendar](https://biodynamic-gardening-calendar.streamlit.app/) its own icon and name on a phone or tablet
home screen. Opened from the home screen, it goes straight to the calendar app. Opened in a browser, it shows an
"Open the calendar" button and how to add it to the home screen.

* The calendar's address is in one line of `index.html`: `var APP_URL = "...";`
* Published with GitHub Pages (Settings > Pages > Deploy from a branch > main, / (root)).
